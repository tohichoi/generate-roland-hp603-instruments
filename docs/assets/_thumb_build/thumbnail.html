BankNumber =
CC#0 × 128 + CC#32
MSB × 128 + LSB  →  one 14-bit address
16,384 banks  ×  128 programs
Both vendors transmit the identical 3 bytes into the identical address space. They simply carve it up differently.
Not interchangeable. A Roland bank number resolved on a Yamaha map lands on an unrelated voice — and the reverse. Each map had to be reverse-engineered from its own implementation.
